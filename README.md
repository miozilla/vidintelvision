# vidintelvision 🩻📺🧠
vidintelvision : | Video Intelligence &amp; Cloud Vision | User-Generated Content Scanner, API, Pub/Sub, Cloud Run Function, BigQuery, Bucket |


## Objectives
- To implement intelligent image & video filtering (ADULT, VIOLENCE, SPOOF, MEDICAL).
- To use Vision API safe-search feature & Video Intelligence API explicit content detection.
- To eliminate unsafe or undesirable images & videos before processing (Social Marketing Campaigns - contests, testimonials or website content)
- Deploy 4 Cloud Run functions.
- Create supporting Cloud Storage buckets, Cloud Pub/Sub topics & Cloud Storage Pub/Sub Notifications.
- Create supporting BigQuery dataset & table.
